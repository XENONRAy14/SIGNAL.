# Références des connecteurs

Documentation consultée le 2 octobre 2026. Les API tierces peuvent évoluer ; vérifier les contrats avant d’activer de nouvelles sources.

- Greenhouse Job Board API : https://docs.greenhouse.io/job-board.html
- Lever Public Postings API : https://github.com/lever/postings-api
- Ashby Public Job Posting API : https://developers.ashbyhq.com/docs/public-job-posting-api
- SmartRecruiters Posting API : https://developers.smartrecruiters.com/docs/posting-api
- SmartRecruiters endpoints : https://developers.smartrecruiters.com/docs/endpoints
- Recruitee Careers Site API : https://docs.recruitee.com/reference/intro-to-careers-site-api
- Recruitee public offers endpoint : https://docs.recruitee.com/reference/offers

- France Travail API Offres d’emploi v2 : https://francetravail.io/data/api/offres-emploi (licence : afficher l’intégralité de l’offre, la source, la date de mise à jour et un lien)
- Adzuna API : https://developer.adzuna.com
- Arbeitnow Job Board API : https://www.arbeitnow.com/blog/job-board-api
- Remotive API : https://remotive.com/api-documentation (non utilisée : robots.txt interdit /api/* à tous les agents)
- RFC 9309 Robots Exclusion Protocol : https://www.rfc-editor.org/rfc/rfc9309

Les tests utilisent des fixtures minimales conformes aux formats documentés. Ils ne remplacent pas des tests de contrat périodiques contre les fournisseurs.
